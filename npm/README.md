# @veltrea/floatingmacro-mcp

MCP stdio server for [FloatingMacro](https://github.com/veltrea/floatingmacro). A thin proxy that lets MCP-compatible AI clients (Claude Desktop / Claude Code / Cursor / Gemini CLI / VS Code Copilot / Windsurf) drive a running FloatingMacro instance over stdio.

## Quick start

Make sure the FloatingMacro app is running, then add this server to your MCP client.

### Claude Code

```bash
claude mcp add floatingmacro-stdio npx -- -y @veltrea/floatingmacro-mcp \
  --token "$(cat ~/Library/Application\ Support/FloatingMacro/control_api_token)"
```

### Cursor (`~/.cursor/mcp.json`)

```json
{
  "mcpServers": {
    "floatingmacro-stdio": {
      "command": "npx",
      "args": ["-y", "@veltrea/floatingmacro-mcp", "--token", "<TOKEN>"]
    }
  }
}
```

### Gemini CLI (`~/.gemini/settings.json`)

### Token retrieval

The bearer token is auto-generated by FloatingMacro on first launch and stored in `~/Library/Application Support/FloatingMacro/control_api_token` (mode 0600), with a Keychain mirror for `security` CLI compatibility. Retrieve it with:

```bash
cat ~/Library/Application\ Support/FloatingMacro/control_api_token
# or, equivalently, via Keychain:
# security find-generic-password -s FloatingMacro -a ControlAPIToken -w
```

The FloatingMacro app's "AI 連携" window has a "CLI 登録" button that fills this in automatically for each supported client.

## Why use this?

FloatingMacro already exposes an HTTP MCP endpoint at `http://127.0.0.1:17430/mcp`. Most clients can hit it directly. Use this stdio package when:

- Your client only supports stdio MCP transport (e.g. Claude Desktop free plan)
- You want a uniform stdio-only setup across all your clients
- HTTP transport is blocked by your environment (proxies, firewalls)

## Options

| Flag | Description | Default |
|---|---|---|
| `--port N` | FloatingMacro HTTP API port | `17430` |
| `--token TOKEN` | Bearer token (or `FLOATINGMACRO_TOKEN` env) | empty |
| `--help`, `-h` | Show help | |
| `--version` | Show version | |

## Behavior

- **JSON-RPC over stdio** (one envelope per line). No Content-Length framing — that's LSP, not MCP.
- **Pure proxy**: every `tools/call` is forwarded to `POST /tools/call` on the running FloatingMacro app.
- **Does NOT launch FloatingMacro**: if the app isn't running, calls return `-32000 FloatingMacro app not reachable`.
- **Multiple instances are safe**: each spawned process is independent.
- **No keychain access**: the token must be passed via `--token` or `FLOATINGMACRO_TOKEN`.

## Manual sanity test

```bash
printf '%s\n' \
  '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{}}' \
  '{"jsonrpc":"2.0","id":2,"method":"tools/list","params":{}}' \
  '{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"ping","arguments":{}}}' \
  | npx @veltrea/floatingmacro-mcp --token "$(cat ~/Library/Application\ Support/FloatingMacro/control_api_token)"
```

Expected: 3 JSON lines, the third being `{"id":3,"result":{...ok:true...}}`.
